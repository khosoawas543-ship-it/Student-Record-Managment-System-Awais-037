# Student record management system

A GUI-based student records management system built in C++ using MFC (Visual Studio 2022).
Created for SW112 Programming Fundamentals at MUET Khairpur. ## Features
- Add new student entry
- Update existing files (registration number is a unique identifier)
- Delete entry
- Browse through the entries using the "Next" button.
- Press the clear button to return to add mode.
- Validation: Empty field, repeat roll number, GPA range (0-4).

## Data storage
Recordings are saved in the "records.txt" file, with one student per line separated by commas.
Name, roll number, father's name, caste, district, GPA

## Tools used
-C++
-Microsoft Visual Studio 2022.
- MFC (Microsoft Foundation Course)

## How to run
1. Open “Student Record System.sln” in Visual Studio 2022.
2. Press Ctrl+F5 to build and run.
